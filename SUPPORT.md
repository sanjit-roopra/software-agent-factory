# Support

Software Agent Factory is an alpha project for local macOS use.

## Get help

- Read the [documentation](https://sanjit-roopra.github.io/software-agent-factory/).
- Run `factory doctor`.
- Search existing [issues](https://github.com/sanjit-roopra/software-agent-factory/issues).
- Open a bug report if the problem is reproducible.

## Supported

- the latest release
- Python 3.13 and 3.14
- macOS
- source installs with `uv`
- published macOS release archives

## Not supported

- hosted or multi-user deployments
- Linux or Windows production use
- automatic merging or deployment
- old releases
- custom forks or private integrations

Support is provided when maintainer time allows. There is no response-time
guarantee.

Report security problems through [SECURITY.md](SECURITY.md), not a public issue.
