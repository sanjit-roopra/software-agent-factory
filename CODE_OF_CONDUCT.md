# Code of Conduct

We want this project to be useful, safe, and welcoming.

## Expected behavior

- Be respectful and patient.
- Discuss ideas and code, not people.
- Give clear, useful feedback.
- Accept that others may have different experience or context.
- Protect private information.
- Help keep issues and pull requests focused.

## Unacceptable behavior

- Harassment, threats, or discrimination.
- Personal attacks or repeated hostile comments.
- Publishing private information without permission.
- Sexualized language or unwanted attention.
- Deliberately disrupting project work or community spaces.

## Reporting

Report conduct problems privately using the contact details on the
[maintainer's GitHub profile](https://github.com/sanjit-roopra).

Do not use a public issue for a report that contains private information.

The maintainer will review the report, protect the reporter's privacy, and take
action that fits the situation. This may include a warning, removing content,
or limiting participation.

## Scope

This policy applies in repository discussions, pull requests, issues, and other
project spaces.
