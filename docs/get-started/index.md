# Get started

Three pages, in order.

[Install](install.md)
: Source checkout with uv, a released macOS archive, or a wheel. Includes the
  external tools the factory expects on `PATH`.

[First offline run](first-run.md)
: Drive one work item through the whole pipeline with the deterministic fake
  runtime. No network, no cost.

[Real Copilot runs](copilot.md)
: Switch to `--runtime copilot`, what it spends, what it can touch, and how it
  fails.

Once a run finishes, continue to [Configure a repository](../guides/configure-repository.md)
to make the factory run your project's real lint, tests and build.
