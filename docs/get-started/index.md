# Get started

Three pages, in order.

<dl class="saf-index" markdown>

<dt>[Install](install.md)</dt>
<dd>Source checkout with uv, a released macOS archive, or a wheel. Includes the external tools the factory expects on `PATH`.</dd>

<dt>[First offline run](first-run.md)</dt>
<dd>Drive one work item through the whole pipeline with the deterministic fake runtime. No network, no cost.</dd>

<dt>[Real Copilot runs](copilot.md)</dt>
<dd>Switch to `--runtime copilot`, what it spends, what it can touch, and how it fails.</dd>

</dl>

Once a run finishes, continue to [Configure a repository](../guides/configure-repository.md)
to make the factory run your project's real lint, tests and build.
